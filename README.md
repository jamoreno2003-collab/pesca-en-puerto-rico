# Pesca en Puerto Rico

Sitio estático adaptable a computadoras y celulares, creado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: secciones Inicio, Lugares, Equipo y Contacto.
- `style.css`: diseño responsive y estilos accesibles.
- `script.js`: menú móvil, navegación activa y formulario de demostración.
- `assets/logo.svg`: logo vectorial.

## GitHub Pages
El sitio se publica automáticamente mediante GitHub Actions. En Settings → Pages, la fuente de publicación debe ser GitHub Actions. Las fotografías y fuentes externas requieren conexión a Internet.

## Formulario
El formulario valida los campos en el navegador, pero no envía ni almacena información. Para recibir mensajes reales, debe conectarse a un servicio o servidor.

## Pesca responsable
Los lugares mencionados son sugerencias generales. Verifica acceso, permisos y reglamentos vigentes antes de visitar una zona.
